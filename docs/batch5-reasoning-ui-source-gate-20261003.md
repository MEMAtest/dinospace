# Batch 5 reasoning UI source gate — 2026-10-03

## Implemented in this source candidate

- Amari gets the new Colour Mixing Lab and Odd One Out routes for `colormix` and `oddoneout`; Amari's Sound Safari and Spelling Studio routes remain active for `phonics` and `words`. Askia retains the catalog's existing components. These four games bypass the generic level/session wrapper so chapter completion, badges and six-round results have one owner.
- Both new games show a three-chapter map, six seeded missions per run, replay with a fresh seed, recent-ID queues passed into the committed generators, map-lock progression and child-controlled Next. Results are persisted only after all six correct canonical mission results advance from the final held fact. Celebration is called only when the stored best-star score increases.
- Colour Lab uses named swatches and the authored equal one-part colour model. Input tasks show the known input and a neutral missing-input pot; the correct addition and output beaker appear only after selection. Design briefs keep their target colour visible while the selected recipe stays hidden. Successful mixes animate into a beaker, with reduced-motion support. The saved palette shows each persisted colour and its canonical classroom recipe/fact.
- Odd One Out displays the authored property before the picture choices. A correct item selection opens a separate “Because…” step. Wrong items/reasons can be retried; the one-use hint exposes the rule explanation without selecting an answer. Object and feature choices use local vector illustrations, labels, and targets sized for touch.
- The new components use stable optional cancellation on replay, Next, internal chapter-map transitions and unmount. Confirmed route changes are cancelled by App's existing route cleanup. Keep-playing is not an action in these chapter flows.
- All four components report their `start`, `play`, and `done` phases through App's stable optional `onPhaseChange` callback. Chapter maps and finish screens therefore use the parent's no-confirmation leave behavior, while active rounds remain guarded.
- App passes the existing voice cancellation function. All four Batch 5 Amari routes remain profile-scoped; the original catalog entries and Askia components remain available. External event IDs use the catalog IDs (`phonics`, `words`, `colormix`, `oddoneout`) and answer events include the existing learning adapter fields without logging authored prompt text into diagnostics. `firstAttempt` means no earlier wrong choice for that mission; `independent` additionally requires no hint. A successful spelling answer uses one canonical `answer_correct` event, avoiding duplicate learning credit.
- Odd One Out illustrations are self-contained labelled SVGs for the authored categories, shapes, and numbers. Category illustrations are deliberately simplified drawings, not photographic references; they use no remote or emoji-only assets.
- Narration has a separate offline inventory and a read-only readiness script. Neither script is imported by application runtime. No provider calls or audio generation occurred.
