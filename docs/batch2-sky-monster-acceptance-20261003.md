# Batch 2 independent production acceptance — Sky Shapes and Monster Math

**Date:** 3 October 2026  
**Decision:** **Not accepted for 4.5/5. Hold.** This is fresh, independent production gameplay evidence for the canonical release, not candidate-build evidence. Both games completed the scoped six-run matrix (three bands at desktop and 390 CSS px). Several user-facing defects remain, one required Growing Math case was not generated in those six runs, and production narration/audio QA remains open.

## Release and method

- **Canonical site:** [dinospace-eight.vercel.app](https://dinospace-eight.vercel.app)
- **Production release bound for this run:** source SHA `d31239453edf438b5a88ab788db942f2dae76fea`, deployment `dpl_H9rc2Rinyamg7bCf7WdcHeWDVFmz`; browser assets `index-Cp2ikb4I.js` and `index-Bwl2SrXA.css`, matching the production identity recorded in [production health 2026-10-02](production-health-20261002-2247.md). These findings describe that release only. Later source or deployment changes are not covered.
- **Sessions:** isolated headed Chrome desktop at 1280×800 and separate iPhone 15 emulation at 390×844. Each session blocked `/api/voice` and `/api/story` before selecting Amari. No provider stories or paid narration calls were allowed. Only synthetic built-in profiles were used.
- **Seeds:** ordinary Start/Next controls generated every run seed. Diagnostic JSON was downloaded through Grown-ups → Game troubleshooting → Download game log. No PRNG, answer, unlock, or progress injection was used.

The complete two-part Cloud House trace then used DevTools `Input.dispatchTouchEvent` touch start/moves/end over the visible guide coordinates. This is browser-emulated touch, not a physical handset test. Keyboard was used for the remaining mobile Sky flights. Desktop Sky used mouse tracing and keyboard flights.
- **Existing baseline:** the production/roadmap documents provide prior evidence; none of those runs were counted as these six. The diagnostics and images below are from this independent session. The mobile Growing run was restarted once after a deliberately abandoned start; only the completed seed is counted.

## Observed defects and open gates

1. **Sky global reward total is wrong and the mission copy does not explain the distinction.** Every perfect flight said `100% accurate · 3 stars earned`, showed `3 of 3 accuracy stars`, and said `Your sky-stars are saved with this mission.` Yet the desktop home counter showed **18** after 12 perfect flights (preserved in [desktop home screenshot](../output/playwright/batch2-sky-monster-acceptance-20261003/sky-desktop-home-after-12-missions-18-stars.png)). On the isolated mobile profile, Monster contributed 9 and the 12 perfect Sky flights then raised the total from 9 to **27**—18 for Sky. The mission UI never states that the 3 accuracy stars translate into a smaller global award. Production therefore fails the reward-accounting requirement and the reward is ambiguous. Parent source review identified the expected corrected 12-flight total as 42 Sky stars (36 flight stars plus six one-time chapter bonuses); this expected value is not a claim about the deployed UI.
2. **Monster Math labels available/unearned episodes as locked.** On both desktop and mobile, the Episode 1 intro had Episode 1 selected and `Start six questions` enabled, while all three reward pills said `locked`. After earning Episode 1, Episode 2 was available/selected but its pill still said `locked`; the actually disabled Episode 3 was also labelled `locked`. [Desktop intro screenshot](../output/playwright/batch2-sky-monster-acceptance-20261003/monster-desktop-intro-episode-pills-defect.png).
3. **Monster feedback repeats the same clue/explanation twice.** The duplicated sentence appeared after a correct answer and after showing a clue, including the Story episode. [Wrong-answer feedback](../output/playwright/batch2-sky-monster-acceptance-20261003/monster-desktop-starter-wrong.png), [duplicated clue](../output/playwright/batch2-sky-monster-acceptance-20261003/monster-desktop-starter-duplicated-clue.png), [duplicated explanation](../output/playwright/batch2-sky-monster-acceptance-20261003/monster-desktop-starter-explanation-duplicate.png).
4. **Story subtraction number line is incomplete before answering.** For mobile `15 − 13`, the initial line showed 13–17 and omitted both the destination 2 and the 13 backward jumps. For desktop `18 − 12`, the initial window was 16–20, omitting destination 6. Once the correct response was chosen, the line expanded to include the correct landing and route. This prevents a learner from following the displayed model before choosing.
5. **Audio remains unverified and is an explicit open acceptance gate.** Provider routes were blocked before profile selection. A single controlled desktop “Hear the question again” request received the intentional QA 503 block; sound was switched off for gameplay. This proves the provider block, not playback quality. No physical listening test was performed, and the packaged narration integration is not live. Missing narration is expected for this baseline and prevents 4.5 acceptance.
6. **Additional required Growing case remains unverified.** Neither generated six-question Add and Take Away queue contained an addition whose first addend was greater than 10. I did not broaden the run count to chase a specific random item.
7. **Mobile replay uniqueness was not tested.** Bounded UI replays were performed on desktop for each game and produced different seeds/initial questions. The six-run scope did not include a replay on the mobile sessions. The Sky restart control was verified in the desktop Starter band; restart in Growing and mobile restart remain unverified.

## Interaction, persistence, and diagnostics checks

- **Correct/wrong/hint:** Monster Starter deliberately selected a wrong count, received the non-shaming “Try the clue, then count the model again” guidance, used the visible clue and corrected it. Story Challenge also included wrong answers and clues. Sky desktop used the visible tracing hint and restart control.
- **Results, replay, unlock, navigation:** both games completed all three bands in each viewport; next-band unlocks and completion/results screens appeared. Desktop replay of Monster Starter generated a new seed (`3595644919` vs initial `3138295560`) and a different first count (10 vs 8); it was intentionally left incomplete. Sky Starter replay also generated a distinct seed (`4151411459` vs `3172505426`) and was left incomplete. These are bounded desktop replay deltas, not extra completed runs; mobile replay uniqueness remains unverified.
- **Leave/cancel/back:** desktop Sky tested leave → Keep playing (the active flight progress remained) and leave → Back to world (returned to the creative world). Mobile left an in-progress Growing start through Back to world; the app returned to Creative Lab.
- **Reload/profile isolation:** after mobile completion, reload returned to the profile chooser; selecting Amari restored 27 stars. Switching to the synthetic Askia profile showed 0 stars, then switching back to Amari retained 27. Evidence: [Askia isolation](../output/playwright/batch2-sky-monster-acceptance-20261003/sky-monster-mobile-askia-isolation.png), [Amari after return](../output/playwright/batch2-sky-monster-acceptance-20261003/sky-monster-mobile-amari-27-stars.png).
- **Viewport:** mobile document width and viewport were both 390 CSS px during the Sky board check; no horizontal overflow was observed. Minimum 48px size of every interactive target was not exhaustively measured and remains unverified.
- **Console/network:** desktop showed one console error corresponding to the intentional blocked voice test and zero warnings; the provider endpoint returned the deliberate `QA provider block` response. Gameplay ran with sound off. No other material failed asset was observed. Physical audio quality is not inferred from HTTP.

## Acceptance conclusion

The run matrix is complete for this production baseline: three bands × two viewports per game. Two desktop replay deltas were also completed; mobile replay uniqueness remains unverified. The runs are **not passing acceptance**. Sky reward accounting and copy fail; Monster episode pills and repeated feedback fail; Challenge’s pre-answer subtraction model fails; a required Growing addition case is unverified; and live audio/narration QA remains open. Do not claim 4.5/5 for either game from these results. A later candidate/deployment needs its own narrow regression retest for every repaired production defect; these `d312394…` results must remain labeled as the pre-fix production baseline.
