# Batch 7 — Memory Match and Solar System

The final batch contains two games because the full catalog is 26. This work retains the existing eight Memory boards and nine Solar destinations. It does not replace completed earlier batches or claim acceptance.

## Memory Match contract

- Preserve first-five pair counts 4→8→10→12→13 and the later 14/15/16-pair boards. Level completion cannot return to level1; locked boards remain locked until completed normally.
- Every new board is seeded; ten seeds per level have distinct valid layouts, exactly two of every picture, stable IDs and no exposed face-down names. Active boards never reshuffle.
- Teach row scanning, grouping and recall. A completed board may change the next-run strategy, never the active board or its pair count.
- Independent real-browser walkthrough: mismatch lock/timer cleanup, each board completion, restart/replay variation, last-level replay, reload progression, parent navigation, child isolation, mobile card sizes and accessibility. Existing source-level layout and progress evidence is not rendered acceptance.
- Premium themed artwork/animation, independent completed-board sticker/replay reward checks, packaged narration, reduced-motion/device checks and production Playwright remain review gates. Current emoji face artwork is explicitly not final visual acceptance.

## Solar System contract

- Eight planets plus Pluto (explicitly dwarf planet), nine working destinations via strip and scene, with mobile Previous/More scroll buttons and a readable selected state.
- Guided first mission: choose world → three discoveries → challenge. Every authored discovery is visible and read individually; compare and challenge facts remain meaningful.
- Canonical fact/quiz passport persists for Amari only, excludes unknown keys, survives reload, and explicitly warns when storage fails. Discoveries and first challenge credit must not duplicate after reload or repeated clicks.
- Challenge choices shuffle by a per-visit seed; don't reveal answer by fixed position. Independently verify every planet’s actual choices and correct/wrong feedback, passport count, final completed states, scene controls, parent Explore Back and no trapped mobile layout.
- Verify physical/native narration, editorial planetary facts against primary sources, artwork/reduced motion, completion stickers, exact build identity and canonical production Playwright. Existing procedural 3D renderer is preserved pending visual review.
