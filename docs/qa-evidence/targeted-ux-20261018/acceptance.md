# Targeted 5/5 acceptance contract — 18 October 2026

Scope: Astronaut Academy, Curriculum Quest and Code Cadets. Root independently rehearses the Luna implementation through actual controls at 1440px and 390px. Each of the five criteria below must pass for each activity; an untested criterion stays pending. This is scoped acceptance, not a claim about all catalogue games.

## Common five-point bar

1. Clear entry: child sees one plain-language purpose and one obvious first action. Technical skill identifiers, school-term tags and advanced tools do not compete for attention.
2. Focused play: one current question/task; relevant visual and answer/program controls only. Learning preview cannot masquerade as a live question. Primary action reflects the current state.
3. Teaching and recovery: instruction demonstrates the needed idea; wrong attempt is safe and understandable; correct result supplies a useful explanation/fact; feedback stays until child advances.
4. Coherent progression: complete start-to-finish, next/replay/retry and parent-world navigation. Queue/program does not unexpectedly reset. Required saved data survives leave/reopen; existing records remain readable.
5. Visual/accessibility quality: premium shared art, consistent meaningful icons, clear hierarchy, >=44px main touch targets, no clipped/overlapping controls or horizontal/nested-scroll traps at desktop/390px. No application console errors or missing required images.

## Astronaut Academy

- Consolidate seven overlapping categories into three understandable missions, retaining reviewed facts and purposeful question coverage.
- First mission visibly recommended. Other missions accessible without seven simultaneous choices/submenus.
- Play each mission through wrong -> retry -> correct -> explanation -> next -> completion -> replay.
- Updated mission artwork/icons with no emoji-only categories or portrait-loading blank state.
- Facts wait for explicit child continuation; no surprise timed dismissal.

## Curriculum Quest

- Module entry says explore/learn, not Find Africa before the answers can be used. Start action is explicit and singular.
- Geography, history and science share clear learn/play/feedback/completion states.
- During question: no vocabulary wall, repeated listen controls, technical progress labels, difficulty chooser or competing restart/start controls.
- During feedback: correct fact and next action visible near the task; answer controls no longer invite another answer. Wrong feedback remains retryable.
- Complete each module queue, verify final question does not restart unexpectedly, replay presents a new stable queue, and badges remain available away from active task.
- Time-telling practice remains discoverable from history without being confused with chronology.

## Code Cadets

- First action is obvious without needing to read a dense manual or understand all tools.
- Complete first sequence with progressive command guidance and visible rover-facing direction.
- Run wrong debug program then repair directly, without adding/moving an unrelated block through multiple rows.
- Introduce repeat using a visible worked path; finish repeat/collect mission.
- One clear Run/Next action. Save/open/step/undo/mission switching are secondary unless needed.
- Advancing a completed mission does not produce a confusing unsaved-program confirmation.
- Save/reopen a real four-block repeat program, retry a wrong route, recover, replay and return to Creative Lab.

## Release gates

Review source and focused meaningful tests; build/lint; root hands-on local rehearsal; preview identity and rehearsal; production promotion and canonical identity; final production rehearsal. Preserve provider generation guards and use one contained synthetic browser. No paid voices/stories or monitoring restart. Record remaining limitations rather than assigning an unsupported perfect score.
