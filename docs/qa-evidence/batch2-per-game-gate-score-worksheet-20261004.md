## Decision

**No game is newly awarded 4.5.** The current score fields below are deliberately `null`: the evidence is split across distinct source identities and narrow runs, with shared acceptance gates still open. A build, a passing scene, a 48px target audit, and a production deployment identity each answer different questions; none substitutes for a fresh five-dimension review of the exact released game.

The roadmap weights these five 0–5 dimensions equally: **age-6 teaching; meaningful progression; correctness and fair variation; feedback/audio/visual usability; reliability/navigation/persistence.** Acceptance requires an average of at least 4.5, no dimension below 4, and every shared and game-specific gate to pass. An unobserved dimension is not scored as zero and does not pass by inference.
