- **Purposeful progression:** Puzzle Pop has three 2×2, 3×3, and 5×5 chapters; the 4 October 390px run completed four Starter and four Growing scenes and unlocked Challenge. Sky Shapes has four authored missions in each of three skies. The roadmap’s named comparable-route allowance explicitly accepts this route: Starter outlines, Growing curves/inward corners/two-part house, Challenge ordered multipart outlines. Do not expand it to 5–8 question rounds or treat guide points as separate questions. Monster Math changes skill from counting to add/subtract to story problems.
- **Randomization and stable runs:** Puzzle and Sky seeded queue/rotation behavior is covered by source tests and prior independent replay reports. Monster’s run builder freezes six distinct questions, independently shuffles answer positions, and avoids the last eight eligible questions where its pool permits; tests cover seeded model validity and answer balance. These tests support implementation correctness, not natural UI proof of every exceptional prompt.
- **Learning and held feedback:** Current Puzzle UI showed strategy by chapter, mapping hint, wrong-placement retry, and one fact held until Next. Sky’s 2923 accessibility-copy repair passed a narrow desktop keyboard and 390px pointer mission, with the understandable progress message, completion fact/stars, and Next. Monster’s f72 desktop/mobile run showed one-use clue, wrong retry, one held explanation, and Next. Source/test review confirms the ten-frame teaching sentence is suppressed after clue or answer. The exact 2 + 10 UI case is still unobserved.
- **Parent navigation, rewards, and persistence:** Prior identity-bound production matrices and narrow repair reports cover return to the correct parent world, Keep/Back confirmation, chapter/episode unlock, replay, held facts, and saved stars/rewards. Puzzle’s recent replay rotation, Sky’s save/reward repair, Monster clue/header changes, and sound preference each have their own later identity-specific deltas. Treat these as linked release lineage, not as one fresh all-games run.
- **Keyboard and touch-sized controls:** Puzzle’s retained full chapter gates include keyboard and ordinary button-based placements at desktop and 390px. Sky retains keyboard/mouse route evidence and narrow mobile pointer checks. Monster retains visible answer/clue/number-line control evidence. These are browser controls and viewport emulation, not physical handset certification.
