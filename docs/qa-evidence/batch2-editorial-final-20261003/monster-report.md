## Concrete improvements to reach the 4.5/5 bar

These items distinguish product work from acceptance proof. The targeted checks below should use the final production identity and preserve the existing baseline; they do not require replaying all 24 runs unless a broader change invalidates that baseline.

1. **Remove the known duplicate worked explanation.** The 6b production run showed the same “2 counters and 10 more make 12 counters.” sentence in both the model card and feedback panel for `2 + 10`. Keep the solved equation/model, but present one explanatory paragraph. On the repaired production identity, answer that exact Growing question and assert: one model result, one distinct feedback paragraph, same total in the equation, question held until Next, and no repeated copy after clue/correct-answer transitions. This is a concrete defect, not merely a missing test.
2. **Make number-line count-back an action the learner can follow.** A tap/keyboard step control that moves one marker per subtraction step could turn the correct static route into age-6 practice. Preserve the existing pre-answer answer-hiding rule; after each step, expose the current position and remaining jumps to sighted and screen-reader users. For a bounded 15−13 case at desktop and mobile, verify exactly 13 backward steps end at 2, each step is announced once, no answer leaks before the learner starts, and the final model agrees with the answer and explanation. This is an enhancement opportunity, not a correctness failure in the current model.
3. **Close the listening gate with human review.** A reviewer should listen to actual packaged narration on the final production identity for names, quantities, operation/story prompts and worked explanations; judge pronunciation, pacing, joins between clips, volume consistency and suitability for age six. Record clip/question identity and pass/fail notes. Browser request and `playing`/`ended` events establish mechanics only and cannot substitute for this judgment.
4. **Verify the affected production deltas.** On the final production identity, check the changed count-picture accessible names before and after a visible answer at both widths (neutral group label, individually named visible objects, matching post-answer count), the Growing duplicate-feedback case above, and mobile Story Next after ordinary scroll (at least 48×48 CSS px, full-width viewport, one-question advance, old feedback cleared).
