# Curriculum Quest art

`geography-world.webp`, `history-world.webp`, `nature-world.webp`, `nature-specimens.webp`, `history-clues.webp`, `robin.webp`, and `guides.webp` were generated for this game from the approved visual references. The UI places readable, interactive HTML over these art assets.

`continent-map.svg` was generated locally from Natural Earth 1:110m country boundaries ([public domain source](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson)). It uses a simplified equirectangular view for early map learning. Country borders are illustrative; the game uses labelled continent and ocean controls for answers.
