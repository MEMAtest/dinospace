# Discovery HQ catalogue artwork, 17 October 2026

Generated with the built-in image generation tool after the user authorised use of their allowance and credits. Five world dioramas and 34 individual game illustrations cover every game listed in the five Amari worlds, including the six activities also available to Askia.

- Original transparent PNGs are retained here; original tool outputs are also preserved.
- WebP runtime copies live in public/art/catalog-v3, at 768px wide for worlds and 640px for games.
- provenance.json records the complete prompt set, source paths and output hashes.
- Titles, descriptions, favourites, badges and navigation remain HTML. Generated illustrations are decorative, not answer keys or teaching diagrams.
- Game catalogue imagery is reused on practice/recent thumbnails and shared GameSession welcome screens. Individual gameplay scenes remain in place.
- This visual change does not confer editorial acceptance or a 4.5 score on any game.
