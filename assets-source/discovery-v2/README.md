# Discovery HQ illustrated assets

Created with the built-in image generation tool on 17 October 2026, using the user's Code Cadets mockups as visual direction. The environment and Pip are standalone images used behind/in the live UI; no UI text, game board or controls are baked into them. Editable original PNGs are preserved here; runtime WebP copies are in public/art/discovery-v2 (176KB and 170KB). SHA256 values are in provenance.json.

The existing Amari astronaut image is reused from src/assets/landing. No new child likeness was generated. Pip is the illustrated robot rover, not an AI agent or external service.
